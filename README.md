# FJNU 校园导航

> **🌐 在线访问：<https://icyteacn.github.io/FJNU-Nav/>**
>
> **🏷️ 当前版本：v1.5.16**（视觉走查：顶栏短名完整显示/私信空态一行/EN 欢迎页与首页夹生清零；不蒜子第三方实时统计三指标随路由导航计数，失败优雅降级）

面向福建师范大学的校园服务聚合入口，暖色系「闽都红」主题、移动端优先。

## 功能

| 应用 | 说明 |
|------|------|
| 🏯 学校官网 | 研究生服务（置顶）/ 教务 / 招生 / VPN / 服务入口大全 |
| 📰 校园动态 | 教务处官网通知/动态，随快照定时更新 |
| 🗓️ 校历 | 官方教学日历列表 + 学期时间线 |
| 🧭 教室导航 | 空教室查询 + 教室一周占用 + 教学楼导航指引 |
| 📚 课程表 | 班级/教室/教师课表查询（数据来自NextFStar API） |
| 🍚 食堂空座率 | 实时空座监测 + 拥挤度进度条 + 档口菜单与菜价 |
| 🎓 研究生服务 | 研究生信息管理系统 / 奖学金测算 / 学术工具箱（文献管理·期刊分区·CCF目录）/ 就业直达 |
| 📈 数据洞察 | 基于课程排课数据的统计分析 |
| 🏃 体测计算器 | 按《国家学生体质健康标准》计算体测总分与等级 |
| 🍲 今天吃什么 | 随机推荐食堂档口，支持多维度筛选（校区/餐次/预算/口味） |
| 💰 生活费计数器 | 收支记账 + 账单导入 + 奖学金预设（研究生标准） |
| 🧠 福star知多少 | 约100题校园知识问答 |
| 🎠 美食轮盘 · 🃏 教学楼速配 | 校园小游戏 |
| 👔 校领导测试 | 35题 + 10位校领导原型（含照片） |
| 💬 贴吧舆情 | 福建师范大学吧热帖分析 |
| 🎖️ 贡献者墙 | 词云式展示项目贡献者 |

## 技术栈

- **前端**：Vue 3 + Vite，路由懒加载，首屏JS 97KB
- **数据源**：NextFStar公开API + 教务处爬虫 + 贴吧爬虫
- **部署**：GitHub Pages（自动构建）

## 本地运行

```bash
npm install
npm run dev        # 前端开发服务器
```

## 部署

推送 `main` 分支即自动部署到 GitHub Pages。

## 目录结构

```
FJNU-Nav/
├── src/
│   ├── config/site.js      # 站点配置（移植入口）
│   ├── router.js           # 路由（懒加载）
│   ├── data/               # 静态数据
│   ├── views/              # 应用页面
│   └── components/         # 可复用组件
├── crawler/                # Python爬虫
├── public/data/            # 静态数据快照
└── .github/workflows/      # CI/CD
```
