## 0. 本次新增的文件（已写好，不用改）

```
mp-schedule/
  cloudfunctions/
    boardWrite/          ← 云函数：发帖/评论先过官方内容安全检测，通过才落库
      index.js
      package.json
      config.json        ← 已声明 security.msgSecCheck 调用权限
```

云函数做的事：

- `post` 发帖：昵称+正文一起送 `msgSecCheck`（scene=3 论坛），suggest=pass 才写入；超 300 字拒绝；同一人 5 秒内只能发一条（防刷屏）
- `comment` 评论：过检（scene=2）后 push 进该条 `comments`，超 200 字拒绝
- `like` 点赞：`likes+1`（无文字不过检）
- 检测失败返回 `{ok:false, reason:'risky'}`，前端下版本会提示「内容未通过安全检测」

## 1. 开通云开发（2 分钟）

1. 打开微信开发者工具 → 打开 `mp-schedule` 项目
2. 顶部工具栏点 **「云开发」** 按钮 → 弹窗点「开通」
3. 环境名随意（如 `fjnu-board`），选**按量付费基础版/免费额度**（每月免费额度：1GB 存储 + 5 万次读 + 2 万次写，班级规模绰绰有余）
4. 记住**环境 ID**（形如 `fjnu-board-xxxxxx`，下面不用填，函数自动取当前环境）

## 2. 建数据库集合

1. 云开发控制台 → 左侧 **「数据库」**
2. 点 **「+」新建集合**，名字必须叫：`suggestions`
3. 权限设置：**「所有用户可读，所有人可写」**
   （当前 v1.3.2 版本是前端直写集合，这步做完建议墙立刻变共享）

## 3. 部署云函数（为下版本预备）

1. 回到开发者工具，目录树里会出现 `cloudfunctions/boardWrite`
2. **右键** `boardWrite` 文件夹 → **「上传并部署：云端安装依赖（不上传 node_modules）」**
3. 看到「部署成功」即完成；云开发控制台「云函数」里能看到 `boardWrite` 即为成功

> 现在部署好函数但 v1.3.2 还不会调它——下一版（v1.3.3）我把前端写入改走函数后，内容安全检测才正式生效。

## 4. 下版本上线后要做的收尾（到时候我会提醒）

v1.3.3 前端改走 `boardWrite` 函数发布后：

1. 云开发控制台 → 数据库 → `suggestions` → 权限设置
2. 把**写**权限改紧：**「仅管理端可写」**（读权限保持「所有用户可读」）
   ——此后任何人想写墙必须走云函数 → 必过内容安全检测，无法绕过

## 5. 验证方法

- 开通后：两台手机/预览版同时进建议墙，A 发一条，B 下拉刷新能看到 → 共享成功
- 函数生效后（v1.3.3）：发一条含广告/敏感词的帖子，应被拒绝并提示
- 云开发控制台「数据库」里能看到记录，含 `_openid`（自动注入，可溯源但看不到身份明文）

## 6. 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 建议墙顶部仍显示「本机模式」 | 云环境未开通或集合名不对 | 检查第 2 步集合名必须是 `suggestions` |
| 发帖提示「写入失败」 | 第 4 步提前收紧了写权限而前端还没更新 | 先改回「所有人可写」，等 v1.3.3 |
| 函数调用报 `permission denied` | config.json 的 openapi 权限未随部署生效 | 重新右键部署函数 |
| 担心免费额度超 | 班级量级不会超 | 云开发控制台可看用量，超限会停写不会扣费 |
