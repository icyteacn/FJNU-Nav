# 福star课表 · 独立微信小程序（mp-schedule）

可下载课表 App 的小程序版——独立于 `mp-weixin/`（导航站小程序），只含课表功能。

## 页面

| 页面 | 功能（对齐 App） |
| --- | --- |
| `pages/schedule/` | 周视图网格（专业切换、‹第N周›、单双周、节次时间轴、点击看详情）、白底左色条 App 同款课程卡、**下一节课卡**（秒级倒计时+可开关）、近 14 天日程提醒条、搜索入口、网格/列表双模式 |
| `pages/search/` | 课程搜索（名称/教师/教室模糊匹配）+ 类型筛选 |
| `pages/about/` | 设置：默认专业、彩色/单色配色、下一节课卡开关、课前提醒（15/30/45/60 分钟）、联动入口、刷新/导出/导入 JSON/恢复默认 |

## 停课/调课/编辑（与 App 对齐）

- `holidayMap` 节假日整列「🎉假期停课」；调休日列头徽标并按 `scheduleWeekday` 上课
- 调课：调入=蓝虚线卡（自X/X调入）、调出=灰卡（↗已调至X/X）；下节课自动跳过停课日
- 当前周今日列红色**时间轴**（红线+时刻标签）
- **本地编辑覆盖层**：点课程卡→详情/编辑/本周停课/删除全部周；☰菜单→添加课程/设某天停课/清空本地修改；存于 `fjnu_custom/edits/delweek/ovr`，网站数据只读，顶部黄条一键还原

## 数据

与网站同源 `data/schedule-data.json`（站点 → jsDelivr → raw 三源容错 + 本机缓存），单双周 `weekdayType` 与网页版口径一致。全部数据存本机，无个人信息上传。

## 导入

微信开发者工具 → 导入本目录（AppID 已填）→ 预览 → 上传。request 域名同 `mp-weixin/README.md` 清单。

## 与 App 的差异（如实说明）

- 「课前提醒」为展示设置项（小程序无后台通知能力）；桌宠伙伴未移植（养成体系依赖长期本地状态）
- 「编辑本课」作用于整门课，App 的按周差异编辑在小程序里以「本周停课」实现
- 头像资源：`avatar-512.png`（提交 mp 后台基础信息用）
